**학습 목표:** 국내 공간자료의 제공기관·제품·형식·취득 경로를 구분합니다.

**준비:** [실행 환경](../stack.html) · [도구와 용어](../glossary.html). 예제 자료는 별도 표시가 없는 한 합성 자료입니다.

## 개념

공공데이터 포털은 자료를 찾는 입구이고, 데이터셋은 구체적인 파일이나 API 제품입니다. 국토지리정보원(NGII)은 수치지도·수치표고모형 같은 국가 기본 공간정보의 주요 제공기관입니다. VWorld는 공간정보 조회·활용 서비스이며, 국가공간정보포털(NSDI)이라는 이름으로 안내된 예전 링크는 현재 제공 경로를 다시 확인해야 합니다.

서울 열린데이터광장은 서울시 지역 자료를, 공공데이터포털은 여러 기관의 파일·API 목록을 찾는 데 유용합니다. 동일한 '건물' 자료라도 범위와 갱신일, 속성, 라이선스가 다를 수 있습니다.

## 왜 필요한가

분석 코드를 먼저 만드는 것보다 필요한 해상도와 속성을 확보할 수 있는지 확인하는 것이 우선입니다. 건물 외곽선만 있는 자료로 높이·용도를 안다고 가정하면 안 됩니다.

## 핵심 API

이 장의 코드는 다운로드 API가 아니라 취득 계획을 저장하는 Python 표준 라이브러리 json 예제입니다. 실제 요청은 각 제품의 문서, 인증, 좌표계, 호출 제한을 확인한 뒤 작성합니다.

## 시각화와 결과 읽기

포털 이름을 로고로 나열하기보다 '기관 → 데이터셋 → 파일/서비스 → 내 분석 변수' 흐름을 그리세요. 도로 선 데이터와 실제 보행 네트워크는 연결성 처리 수준이 다릅니다.

## 흔한 오류

WMS는 주로 지도 이미지 서비스이므로 분석용 벡터 파일과 같지 않습니다. 무료 열람이 재배포 허용을 뜻하지 않습니다. 접속이 안 되는 예전 URL을 최신 다운로드 경로로 단정하지 않습니다.

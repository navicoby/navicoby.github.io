00 / The idea

같은 조건.
서로 다른 공간 경험.

짧고 직접적인 길도, 길게 돌아가는 산책로도 설계의 출발점이 될 수 있습니다. 가능 여부와 형태의 차이를 구분하는 것이 이 연구의 핵심입니다.

01 — REPRESENT

그림이 아니라, 기하로.

두 출입구를 잇는 곡선을 제어점으로 표현합니다. 중심선과 보행면을 분리해 GIS·CAD·BIM 연계를 준비합니다.

02 — SEPARATE

불가능과 낯섦은 다릅니다.

경계 이탈과 연결 단절은 검증합니다. 길이·굴곡·내부면적은 성급히 제외하지 않고 형태를 설명하는 값으로 남깁니다.

03 — ILLUMINATE

최적안 하나보다, 대안의 지도.

서로 다른 특성의 설계안을 보존하는 Quality–Diversity 탐색을 연구합니다. 설계자가 비교하고 선택할 여지를 남깁니다.

연구 구상은 기존 연구노트에 기반합니다. 격자는 탐색 개념도이며, 계산된 MAP-Elites 결과가 아닙니다.

02 / How it works

생성하고. 검증하고.
다양성을 남깁니다.

기하 생성기와 평가기를 분리합니다. 먼저 해석할 수 있는 곡선으로 시작하고, 검증된 설계안을 특성별로 보존하는 탐색기로 확장합니다.

Ω, S, E, w = 2m

바뀌지 않는 조건을 먼저 정합니다.

부지 경계 Ω와 남측·동측 출입구 S, E를 입력합니다. 보행폭은 2m로 고정합니다. 초기 직사각형 부지에서 시작하되, 실제 필지 polygon으로 확장하는 것을 목표로 합니다.

설계 특성의 공간을 탐색하고 다양한 해를 보존하는 MAP-Elites의 기본 문헌.

데모의 계산 방식과 범위

기하 표현. 각 경로는 두 개의 3차 Bézier 구간으로 구성합니다. 각 구간을 160등분한 점열의 선분 길이를 합산합니다. 면적은 경로 A와 역방향 경로 B로 닫힌 점열에 shoelace 공식을 적용한 근사값입니다.

수치의 의미. 변형 슬라이더는 제어점을 이동시킵니다. 선택된 형태와 슬라이더 값이 같으면 같은 곡선과 값이 표시됩니다. 길이·면적만 계산하며, 품질 점수·탄소량·비용·그늘 성능을 추정하지 않습니다.

구현의 범위. 브라우저에서 실행되는 순수 HTML·CSS·JavaScript 시안입니다. 실제 최적화 실행, GIS 좌표계, 기하 buffer 연산, 장애물 회피, 접근성·시공 검증은 포함하지 않습니다. 화면의 북쪽과 80 × 50m 형상은 가상 대상지의 표시 규칙입니다.

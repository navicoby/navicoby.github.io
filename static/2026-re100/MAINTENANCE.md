# 사이트 관리 안내

공개 주소: https://navicoby.github.io/2026-re100/

기존 `navicoby/navicoby.github.io` 저장소의 `static/2026-re100/`에 들어가는 정적 사이트입니다. 기존 Hugo 배포 과정이 이 디렉터리를 공개 루트의 `/2026-re100/`으로 복사합니다. 상위 사이트의 설정을 바꿀 필요가 없습니다.

## 본문 갱신

1. `docs/`의 Markdown 원고와 `data/sources.json`의 근거 정보를 수정합니다.
2. 수치를 바꿨다면 `data/indicators.csv`도 같은 기준으로 수정합니다.
3. Pandoc과 Python 3가 설치된 환경에서 이 디렉터리의 `python3 scripts/build_site.py`를 실행합니다.
4. 처음 화면의 요약·비율·날짜도 바뀌면 `scripts/build_site.py`의 해당 내용을 수정하여 다시 생성합니다. 첫 화면 수치는 자동 수집되지 않습니다.
5. 생성된 `index.html`, `pages/`, 관련 파일을 함께 반영합니다.
6. 상위 저장소의 기존 배포 작업이 성공했는지 확인하고 실제 공개 주소에서 점검합니다.

별도의 빌드 도구 없이도 생성된 HTML을 배포할 수 있습니다. 외부 글꼴·분석 추적기·유료 API를 사용하지 않습니다. 본문 페이지의 작은 스크립트는 모바일 목차 이동에만 사용합니다.

## 확인할 내용

- 첫 화면과 본문의 출처·날짜·수치가 일치하는지
- 모바일 본문에 가로 넘침이 없는지, 표는 자체 영역에서 스크롤되는지
- 상대경로 링크와 CSV 내려받기가 작동하는지
- 특정 기관의 비공개 내용이나 로컬 경로가 섞이지 않았는지
- 전망·정책 목표를 실적이나 현행 의무로 바꾸지 않았는지

공개판에는 원본 참고 PDF와 조사 중간 파일을 포함하지 않습니다. 확인일은 실제 자료를 재검토한 경우에만 갱신합니다.

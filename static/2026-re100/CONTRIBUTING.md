# 함께 보완하는 방법

이 프로젝트는 시민·학생·실무자가 RE100을 이해할 수 있도록 공개 자료를 읽고 설명하는 공간입니다. 쉬운 문장으로 쓰되, 적용 범위와 불확실성을 생략하지 않습니다.

## 오류 수정과 자료 제안

Issue 또는 Pull Request에 다음을 적어 주세요.

1. 수정이 필요한 문서와 문장
2. 바꾸려는 내용과 이유
3. 공식 원문 링크, 발행일, 실적기간·적용 시점
4. 통계의 분모·단위·대상과 검토상의 한계

보도자료보다 구체적인 규정·통계 원문이 있으면 함께 제시해 주세요. 정책 제안, 입법예고, 확정 규칙, 시행 중 규칙을 구분합니다. 기존 수치와 새 수치의 대상이 다르면 단순한 증감으로 연결하지 않습니다.

## 편집 원칙

- 특정 기관의 내부계획·미공개자료·개인정보를 올리지 않습니다.
- 단가나 업체 사례를 보편적인 추천으로 바꾸지 않습니다.
- 타인의 표·그림·문서 전문은 이용 조건을 확인하지 않고 복제하지 않습니다.
- 근거가 불충분하면 단정을 줄이고 확인이 필요한 부분을 표시합니다.
- 수정한 문서와 출처 목록, 관련 지표 데이터, CHANGELOG를 함께 갱신합니다.
- 상대경로 링크와 한글 표시를 확인하고, 예시 계산의 단위와 합계를 점검합니다.

기여한 직접 작성 문장·표에는 이 저장소의 [CC BY 4.0](LICENSE.md)이 적용됩니다. 권한이 없는 외부 저작물을 이 조건으로 다시 배포할 수는 없습니다.

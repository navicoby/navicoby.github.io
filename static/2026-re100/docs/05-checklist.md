# 05. 첫 검토 체크리스트

[처음으로](../README.md) · [다음: FAQ와 용어](06-faq.md)  
자료 확인일: 2026-09-23

다음은 조직의 초기 검토를 돕기 위해 재구성한 작업 순서입니다. 공식 인증 심사표나 모든 조직에 적용되는 의무 일정은 아닙니다. [기록용 CSV](../templates/re100-checklist.csv)를 복사해 담당자와 근거를 적을 수 있습니다.

## 1. 목적과 판단 기준 정하기

- [ ] 교육·공개, 공급망 요구, 자발적 전환, 공시·규제 대응 중 목적을 적었습니다.
- [ ] 적용 제도와 상대방이 요구하는 기준·버전·기한을 확인했습니다.
- [ ] 그룹·법인·사업장·임차공간의 포함 범위를 정했습니다.
- [ ] ‘얼마나 전환할 것인가’와 ‘어떻게 확인할 것인가’를 함께 정했습니다.

## 2. 사용량과 현장 여건 파악하기

- [ ] 같은 기간의 전력사용량과 전기요금을 모았습니다.
- [ ] 가능한 경우 시간대별 사용량을 확인했습니다.
- [ ] 계량기·전기사용 계약·임대차와 실적 귀속 관계를 정리했습니다.
- [ ] 증설·휴업·전기화·효율개선에 따른 수요 변화를 구분했습니다.
- [ ] 설치 후보지의 사용권, 구조·방수·안전, 음영, 계통 여건을 검토했습니다.

## 3. 조달 대안과 비용 비교하기

- [ ] 가능한 수단을 확인하고 동일한 범위의 총비용으로 비교했습니다.
- [ ] 발전·사용 시간대의 불일치와 부족·초과 처리 조건을 검토했습니다.
- [ ] 가격·수요·발전량이 달라지는 복수 시나리오를 비교했습니다.
- [ ] 공급 개시 지연과 계약 상대방의 이행 위험을 검토했습니다.
- [ ] 특정 비율이나 회수기간을 근거 없이 모든 현장에 적용하지 않았습니다.

## 4. 증빙과 공개 준비하기

- [ ] 실적 인정에 필요한 발전원·기간·시장·설비 정보를 확인했습니다.
- [ ] 환경속성의 귀속과 중복 사용 방지 절차를 정했습니다.
- [ ] 계약서, 정산서, 계량값, 인증서·사용 확인서를 연결해 보관합니다.
- [ ] 실제 사용량과 인정 물량을 대조하고 누락·불확실성을 기록합니다.
- [ ] 목표, 계약, 사용 실적, 검증 결과를 구분해 공개합니다.

증빙 항목의 기준은 [RE100 보고 지침](https://www.theclimategroup.org/re100/technical-guidance)과 [K-RE100 제도 안내](https://www.knrec.or.kr/biz/introduce/new_policy/intro_kre100.do)를 확인하세요.

## 검토가 끝났을 때 남겨야 할 것

| 산출물 | 핵심 내용 |
|---|---|
| 목적·경계 메모 | 왜 하는지, 어디까지 포함하는지, 어떤 기준을 적용하는지 |
| 사용량 표 | 기간, 사업장, 계량 경계, 사용량, 자료 출처 |
| 대안 비교표 | 총비용, 물량, 시간대, 증빙, 이행 위험 |
| 증빙 대장 | 고유번호, 대상 물량, 사용기간, 소유·사용 상태 |
| 공개 초안 | 달성 범위, 확인 방법, 한계, 다음 확인일 |

마지막에는 **요구한 조건을 충족했는지**와 **그 조건이 처음의 목적에 적절했는지**를 각각 점검합니다. 예를 들어 연간 인정 비율을 달성했더라도 전력비 안정이나 지역 재생에너지 확대라는 별도의 목적은 추가 평가가 필요합니다.

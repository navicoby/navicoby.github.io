# 05. 실행계획과 검토 체크리스트

자료 확인일: 2026-09-23

실무 해설 보강: 2026-10-05. 아래 일정·역할·산출물은 이 안내서의 제안이며 기관별 의무 절차를 뜻하지 않습니다.

## 공공기관·다수 사업장은 경계부터 정리하기

사옥만 검토하다 외부 사무소를 빠뜨리거나, 소유한 건물의 입주자 사용량까지 기관 실적으로 합산하면 분모가 달라집니다. 먼저 ‘소유자’, ‘전력 구매자’, ‘운영·통제 주체’, ‘실적 주장자’를 나누어 기록하세요. 관리비를 납부하거나 건물을 소유한다는 사실만으로 귀속이 결정되는 것은 아닙니다.

| 대상 공간·설비 | 처음 확인할 자료 | 실무 검토 질문 |
|---|---|---|
| 직접 사용하는 사옥 | 전력계약, 계량기, 사용량 | 보고 경계 안의 사용량을 빠짐없이 집계했는가? |
| 임차 사무실 | 관리비 명세, 배분 산식, 임대차 조건 | 사용량과 환경속성을 누구에게 배분하며 중복 주장은 없는가? |
| 임대주택·임대상가 | 세대·공용부 계량, 계약·운영 관계 | 입주자 사용과 기관 운영분을 어떻게 구분했는가? |
| 위탁운영 시설 | 위탁계약, 요금 납부와 운영 권한 | 회계·보고 기준에 따른 귀속 근거가 있는가? |
| 태양광·충전설비 | 발전·수전·판매 계량, 이용자 구분 | 발전량·자가소비·외부 판매를 분리하고 중복 집계하지 않았는가? |

이 표는 포함 여부를 일률적으로 결정하는 표가 아닙니다. 먼저 적용할 보고 기준을 정하고 경계 판단을 문서화해야 합니다. K-RE100의 참여 안내는 수전받는 입주기업 등도 등록 가능하다고 설명하지만, 수단별 자격과 증빙 절차는 별도 확인이 필요합니다. [S07 국내 참여대상](https://www.knrec.or.kr/biz/introduce/new_policy/intro_kre100.do)

## 90일 동안 무엇을 결정할 것인가

| 시기 | 할 일 | 검토를 마칠 때 남길 산출물 |
|---|---|---|
| 1–15일 | 목적·경계·담당자 확정, 자료 요청 | 사업장·계량기 목록, 적용 기준 목록 |
| 16–30일 | 최근 12개월 이상 사용량·요금 정리, 수요 변화 확인 | 사용량 기준표, 시간대 부하와 결측 내역 |
| 31–45일 | 자가소비 후보지와 외부 조달 가능 조건 검토 | 후보별 예상 물량·개시 시점·제약 목록 |
| 46–60일 | 동일 수요에 대한 비용·위험 시나리오 비교 | 대안별 총비용·증분비용·민감도 표 |
| 61–75일 | 계약·증빙·예산·조달 절차 검토 | 책임 분담표, 증빙 요구사항, 보완 과제 |
| 76–90일 | 연차별 실행안과 연말 실적 확인 방법 확정 | 연도별 물량·예산·일정·성과지표 |

90일은 계획 수립의 예시 기간입니다. 인허가·계통연계·계약심사·설비 시공까지 이 기간에 완료된다는 뜻은 아닙니다. 장기계약과 자산투자는 기관별 예산·계약·재산관리 절차를 확인해 별도 일정에 반영하세요.

## 역할과 성과지표를 함께 정하기

| 담당 기능 | 주요 역할 | 확인할 기록 |
|---|---|---|
| 환경·ESG | 경계·인정 기준·공시 관리 | 산정 근거와 인정량 대조표 |
| 시설·에너지 | 계량·부하·현장 검토 | 사용·발전·자가소비 원자료 |
| 구매·계약 | 공급 조건과 증빙 요구 반영 | 계약서·정산서·이행 점검 |
| 재무·예산 | 연차별 지출과 변동 위험 검토 | 총비용·증분비용·예산 집행 |
| 법무·내부 검토 | 권리·의무·중복 주장 점검 | 쟁점과 시정조치 기록 |

최소한 분기별로 총전력사용량(MWh), 적격 재생전력량(MWh), 전환비율(%), 증분비용(원), 증빙 확인 완료율(%)을 함께 확인하는 운영안을 제안합니다. 증빙 확인 완료율의 분모는 해당 분기에 확인해야 할 조달량, 분자는 그중 검토가 끝난 물량으로 정의할 수 있습니다. 단순한 서류 건수 비율과 혼용하지 않도록 정의를 고정하세요.

발전량, 계약량과 인정량의 차이가 커지면 원인을 계량 누락·공급 지연·배분 오류·증빙 지연 등으로 나누고 담당자와 해결 기한을 정합니다. 기존 환경경영 운영회의와 내부 점검에 이 기록을 연결하면 연말에 자료를 다시 모으는 부담을 줄일 수 있습니다.

## 실행계획의 최소 구성

사업장별 기준 수요, 연도별 목표 물량, 조달 수단과 공급 개시일, 예산, 계약·증빙 책임, 부족 물량 보완안이 서로 맞아야 합니다. 예를 들어 연간 목표 3,000MWh에 대해 자가소비 500MWh와 PPA 2,000MWh를 계획했다면, 남은 500MWh의 확보 방법·기한·예산도 함께 적어야 합니다. 아직 계약하지 않은 물량은 ‘확보 완료’ 대신 ‘검토·협의 중’으로 표시합니다.

아래 체크리스트는 이 실행계획의 누락 사항을 마지막으로 확인하는 용도로 사용할 수 있습니다.

다음은 조직의 초기 검토를 돕기 위해 재구성한 작업 순서입니다. 공식 인증 심사표나 모든 조직에 적용되는 의무 일정은 아닙니다. [기록용 CSV](../templates/re100-checklist.csv)를 복사해 담당자와 근거를 적을 수 있습니다.

## 1. 목적과 판단 기준 정하기

- [ ] 교육·공개, 공급망 요구, 자발적 전환, 공시·규제 대응 중 목적을 적었습니다.
- [ ] 적용 제도와 상대방이 요구하는 기준·버전·기한을 확인했습니다.
- [ ] 그룹·법인·사업장·임차공간의 포함 범위를 정했습니다.
- [ ] ‘얼마나 전환할 것인가’와 ‘어떻게 확인할 것인가’를 함께 정했습니다.

## 2. 사용량과 현장 여건 파악하기

- [ ] 같은 기간의 전력사용량과 전기요금을 모았습니다.
- [ ] 가능한 경우 시간대별 사용량을 확인했습니다.
- [ ] 계량기·전기사용 계약·임대차와 실적 귀속 관계를 정리했습니다.
- [ ] 증설·휴업·전기화·효율개선에 따른 수요 변화를 구분했습니다.
- [ ] 설치 후보지의 사용권, 구조·방수·안전, 음영, 계통 여건을 검토했습니다.

## 3. 조달 대안과 비용 비교하기

- [ ] 가능한 수단을 확인하고 동일한 범위의 총비용으로 비교했습니다.
- [ ] 발전·사용 시간대의 불일치와 부족·초과 처리 조건을 검토했습니다.
- [ ] 가격·수요·발전량이 달라지는 복수 시나리오를 비교했습니다.
- [ ] 공급 개시 지연과 계약 상대방의 이행 위험을 검토했습니다.
- [ ] 특정 비율이나 회수기간을 근거 없이 모든 현장에 적용하지 않았습니다.

## 4. 증빙과 공개 준비하기

- [ ] 실적 인정에 필요한 발전원·기간·시장·설비 정보를 확인했습니다.
- [ ] 환경속성의 귀속과 중복 사용 방지 절차를 정했습니다.
- [ ] 계약서, 정산서, 계량값, 인증서·사용 확인서를 연결해 보관합니다.
- [ ] 실제 사용량과 인정 물량을 대조하고 누락·불확실성을 기록합니다.
- [ ] 목표, 계약, 사용 실적, 검증 결과를 구분해 공개합니다.

증빙 항목의 기준은 [RE100 보고 지침](https://www.theclimategroup.org/re100/technical-guidance)과 [K-RE100 제도 안내](https://www.knrec.or.kr/biz/introduce/new_policy/intro_kre100.do)를 확인하세요.

## 검토가 끝났을 때 남겨야 할 것

| 산출물 | 핵심 내용 |
|---|---|
| 목적·경계 메모 | 왜 하는지, 어디까지 포함하는지, 어떤 기준을 적용하는지 |
| 사용량 표 | 기간, 사업장, 계량 경계, 사용량, 자료 출처 |
| 대안 비교표 | 총비용, 물량, 시간대, 증빙, 이행 위험 |
| 증빙 대장 | 고유번호, 대상 물량, 사용기간, 소유·사용 상태 |
| 공개 초안 | 달성 범위, 확인 방법, 한계, 다음 확인일 |

마지막에는 **요구한 조건을 충족했는지**와 **그 조건이 처음의 목적에 적절했는지**를 각각 점검합니다. 예를 들어 연간 인정 비율을 달성했더라도 전력비 안정이나 지역 재생에너지 확대라는 별도의 목적은 추가 평가가 필요합니다.

# 03. 재생전력 조달 방식 비교

기존 동향·기준 확인일: 2026-09-23 · 실무 해설: 2026-10-05 · K-GX·지분참여 보강: 2026-10-08

## 국내의 기본 선택지

한국에너지공단의 현재 제도 안내에 맞춰 다섯 수단을 정리했습니다. 표의 ‘비교 질문’은 일반적인 검토를 돕기 위한 이 자료의 해설입니다.

| 방식 | 기본 구조 | 비교 질문 |
|---|---|---|
| 녹색프리미엄 | 기존 전기요금에 별도 프리미엄을 납부 | 추가요금, 인정 물량, 증빙 발급 시점은? |
| REC 구매 | 전기 구매와 별도로 적격 인증서를 구매·제출 | 어느 발전소·기간의 속성이고 누가 사용했는가? |
| 제3자 PPA | 한전 중개로 발전사업자와 전기소비자가 계약 | 총비용과 중개·정산 조건은? |
| 직접 PPA | 재생에너지전기공급사업자와 직접전력거래계약 | 공급 개시, 부족·초과 물량, 비용 부담은? |
| 자가소비 | 소유한 설비에서 생산한 전기를 직접 사용 | 사용 시간대, 설치·유지비, 실제 자가소비량은? |

국내 REC 구매는 RPS 의무이행에 이미 쓰인 실적과 중복할 수 없습니다. 실제 활용에는 해당 수단의 자격과 절차를 따라 재생에너지 사용 확인을 받아야 합니다.


**근거 자료:** [S07 재생e 사용 확인(K-RE100)](https://www.knrec.or.kr/biz/introduce/new_policy/intro_kre100.do)

### 지분투자는 어떻게 보나요?

지분투자는 자금을 투입하고 사업에 참여하는 구조입니다. 한국에너지공단 FAQ는 투자 후에도 해당 발전소와 **별도의 PPA 또는 REC 구매계약이 필요**하며 지분·출자비율과 관계없이 계약할 수 있다고 설명합니다. 주주가 됐다는 사실이나 배당금만으로 전력 사용 실적이 생기지는 않습니다. 전력·환경속성의 귀속과 증빙을 확보해야 합니다. [S18 지분참여 공식 FAQ](sources.md#s18)

### 해외의 VPPA를 국내 직접 PPA와 같게 봐도 되나요?

VPPA는 일반적으로 가격 차이를 정산하는 금융적 계약과 환경속성의 이전을 결합합니다. 물리적 전력 인도 계약과 구조가 다릅니다. 해외에서 활용된다는 이유로 국내 모든 전기소비자가 같은 방식으로 이용할 수 있다고 가정하지 않습니다.


**근거 자료:** [S04 RE100 Technical Criteria and Appendices](https://www.theclimategroup.org/re100/technical-guidance)

## 단가보다 같은 범위의 총비용을 비교하기

다음은 **이 자료가 제안하는 비교 방식**입니다. 비용 항목의 실제 적용 여부는 계약과 요금 규정에 따라 달라집니다.

| 검토 대상 | 빠뜨리기 쉬운 항목 |
|---|---|
| PPA 제안 가격 | 망 이용, 손실, 정산·거래 수수료, 부족전력 구매, 초과발전 처리, 세금 등 |
| 자가발전 사업비 | 구조보강·방수, 계통연계, 보험, 유지보수, 인버터 교체, 철거·복구 |
| 기존 전기요금 | 기본요금과 시간대별 사용요금, 계약전력 변화, 고정비 잔존 여부 |
| 장기 계약 | 물가 연동, 물량 의무, 해지·양도 조건, 제도 변경, 신용·보증 비용 |

‘발전소가 생산하는 전기 1kWh의 비용’인 LCOE와 ‘소비자가 공급받는 데 드는 총비용’은 비교 범위가 다릅니다. 프리미엄 추가요금과 전기요금 전체를 직접 비교하는 것도 적절하지 않습니다.

가격을 소개할 때는 **견적·거래 시점, 계약기간, 물량, 전압·접속 조건, 부대비용 포함 범위**를 함께 써야 합니다. 이 안내는 검증되지 않은 단가나 회수기간을 현재의 보편적인 가격으로 제시하지 않습니다.

## 연간 물량과 시간대별 물량

**교육용 가상 예시:** 어떤 사업장은 연간 1,000MWh를 쓰지만 주로 밤에 가동합니다. 연간 예상 발전량이 1,000MWh인 태양광 계약을 맺더라도, 주간 잉여와 야간 부족이 생길 수 있습니다.

연간 재생전력 실적, 시간대별 전력 정산, 24/7 매칭은 각각 따로 검토해야 합니다. 부족전력 비용이나 잉여 처리 책임은 계약을 보고 판단합니다. 특정 비율로 PPA를 시작하는 것을 모든 사용자에게 공통된 공식으로 적용하지 않습니다.

## K-GX를 반영해 조달 제안서에 추가할 항목

**2026-10-08 보강.** K-GX의 공급·제도·지원 방향을 계약과 예산의 검토 항목으로 연결한 제안입니다. 후속 공고에서 자격·시행일·경과조치가 확인된 항목을 실제 비용에 반영합니다.

| 정책 변화 | 제안서에 요구할 자료 | 비교표에 반영할 사항 |
|---|---|---|
| REC 보급제도 개편 추진 | 기존 계약·증빙의 처리와 대체 이행방안 | 제도 변경 시 보완 조달·비용·책임 |
| PPA 망사용료 지원 연장 추진 | 적용 공고, 대상·기간과 산정 근거 | 미확정 지원을 제외한 기준안, 확인된 지원 적용안 |
| 재생에너지 공급·전력망 확대 | 계통접속 상태, 개시 일정, 시간대별 발전 예측 | 지연·출력제어·부족·초과 시 비용 |
| 태양광 발전단가 인하 목표 | 제안 단가의 포함·제외 비용과 유효기간 | 정책 목표와 실제 견적의 구분 |

**정책 근거:** [S16, 본문 pp.14–15·18·46 / PDF 26–27·30·58쪽](sources.md#s16). 원문은 지원요율이나 개별 소비자에게 적용되는 PPA 단가를 확정하지 않습니다. [K-GX 조달 해설](07-kgx.md#procurement)

## 발전사업자와 계약 전에 확인할 질문

1. 부지 사용권, 인허가, 계통접속과 공급 개시 일정의 근거는 있는가?
2. 발전량 예측은 어떤 기상자료·손실률·불확실성을 반영했는가?
3. 환경속성의 소유·이전·사용처와 증빙 제공 책임은 명확한가?
4. 준공 지연, 출력제어, 고장, 조달 부족·초과의 비용을 누가 부담하는가?
5. 가격 조정, 담보, 양도, 중도해지와 제도 변경에 대한 조항은 있는가?

이는 계약 검토의 출발점이며 특정 업체나 투자상품의 추천 목록이 아닙니다.

## 같은 물량을 확보할 때 얼마가 더 드는가

**2026-10-05 보강 · 편집자가 구성한 교육용 가상 예시.** 연간 전력사용량 5,000MWh 가운데 2,000MWh를 재생전력으로 전환한다고 가정합니다. 아래 단가는 모두 임의의 입력값이며 시장가격·견적·수익률 예측이 아닙니다. 비교를 위해 기본요금 등 공통 고정비, 세금과 금융비용은 제외했습니다.

이 예시의 150원/kWh는 임의의 기존 구매요금입니다. K-GX에 제시된 태양광 발전단가의 기준값·목표를 가져온 계산이 아닙니다.

| 가정 | 기존 구매 유지 | 녹색프리미엄 | 인증서 구매 | PPA |
|---|---|---|---|---|
| 기존 전력량요금 | 150원/kWh | 동일 | 동일 | 대체되는 2,000MWh에는 적용하지 않음 |
| 재생전력 조달 관련 입력 | 없음 | 추가 10원/kWh | 속성 비용 25원/kWh | 전력 155원/kWh + 부대비용 15원/kWh |
| 비교 대상의 연간 비용 | 7억 5,000만원 | 7억 7,000만원 | 8억원 | 7억 9,000만원 |
| 기존 구매 대비 증분비용 | — | 2,000만원 | 5,000만원 | 4,000만원 |

PPA 비용은 2,000,000kWh × 170원 + 잔여 3,000,000kWh × 150원 = 7억 9,000만원입니다. 이때 170원은 환경속성까지 포함하고, 2,000MWh가 모두 기존 구매를 대체한다고 가정했습니다. 실제 계약에서는 발전·소비 시간대 불일치, 잉여전력 정산, 잔존 기본요금, 망 이용료와 각종 부담을 다시 계산해야 합니다. 인증서 단가도 가중치가 적용된 REC 개수를 바로 kWh로 간주하지 말고, 사용 확인되는 전력량으로 환산해야 합니다.

> 증분비용 = 같은 수요를 충족하는 전환안 총비용 − 기존 구매 유지안 총비용

> 인정 전력량당 증분비용(원/kWh) = 증분비용(원) ÷ 인정되는 재생전력량(kWh)

첫 식은 전체 예산 영향을, 둘째 식은 목표 1kWh를 확보하는 추가 부담을 보여줍니다. 자가발전은 초기 투자비를 한 해의 전력량으로만 나누지 말고, 분석기간·할인율·유지보수·교체·잔존가치를 같은 조건으로 놓은 생애비용으로 비교해야 합니다.

### 어떤 가정이 바뀌면 선택이 달라지는가

위 예시에서 PPA 총변동단가를 170원/kWh로 고정하면 기존 전력량요금이 130원일 때 증분비용은 8,000만원, 150원일 때 4,000만원, 170원일 때 0원입니다. 공통 고정비 등이 같다는 가정하의 결과입니다. 장기계약의 유불리는 오늘의 단가만으로 판단하기 어렵다는 점을 보여줍니다.

| 바꿔 볼 입력 | 검토할 결과 |
|---|---|
| 전력수요 −10% / 기준 / +10% | 초과계약 위험과 추가 조달량 |
| 발전량 감소·공급 개시 지연 | 부족 물량과 대체 조달 예산 |
| 기존 요금과 PPA 가격 조정 | 연도별 현금흐름과 누적 증분비용 |
| 증빙 누락·인정량 감소 | 같은 지출에서 확보되는 적격 물량 |

## 여러 수단을 조합하는 순서

다음은 이 안내서의 실무 검토 제안입니다. 우선 효율개선과 사업계획을 반영해 향후 수요를 산정하고, 후보지별 자가소비 가능량을 따집니다. 이후 지속적으로 사용할 물량과 계약기간을 바탕으로 PPA를 검토하며, 공급 전 공백과 연말 부족량에 대해서는 이용 가능한 인증서·프리미엄 등 보완 수단을 비교합니다. 각 수단은 요구받는 인정 기준을 충족해야 합니다.

‘PPA 몇 %, 인증서 몇 %’라는 고정 비율을 먼저 정하면 이전·축소·임대차 종료 같은 수요 변화를 놓치기 쉽습니다. 조달 조합은 **수요의 확실성, 예산의 지속성, 현장 여건, 인정 요건**을 함께 보고 정해야 합니다.

## 계약 문장을 검토 항목으로 바꾸기

아래는 법률 조항이나 표준계약서가 아닌 협의 항목입니다. 실제 권리·의무는 해당 계약과 적용 규정으로 정합니다.

| 협의 항목 | 계약서·부속서에 명확히 할 내용 |
|---|---|
| 물량과 가격 | 계량 지점, 시간 단위, 약정 물량, 가격 조정식, 포함·제외 비용 |
| 환경속성과 증빙 | 귀속자, 대상 발전소·발전기간, 중복 주장 방지, 제출 기한 |
| 공급 지연 | 개시일, 지연 통지, 임시 조달 책임, 비용 배분 |
| 출력제어·고장 | 계량량과 정산량의 차이, 면책 범위, 대체 물량 처리 |
| 사업장 변화 | 이전·축소·폐쇄 시 물량 조정, 양도와 해지 조건 |
| 기준 변경 | 인정 기준이 바뀌거나 증빙이 부족할 때 협의·시정 절차 |

계약 체결 전에는 조달 부서만 검토를 끝내지 말고 시설·재무·법무·환경 담당자가 같은 물량표와 비용표를 사용해야 합니다.

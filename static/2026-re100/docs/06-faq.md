# 06. 자주 묻는 질문과 용어

[처음으로](../README.md) · [출처 목록](sources.md)  
기존 동향·기준 확인일: 2026-09-23 · 실무 해설: 2026-10-05 · K-GX 질문 추가: 2026-10-08

## RE100에 가입하면 이미 100%를 달성한 건가요?

가입, 목표 설정, 연간 실적 달성은 서로 다른 상태입니다. 발표의 목표연도와 실제 실적기간을 함께 보세요. [기본 개념](01-basics.md)

## 작은 기업이나 공공기관도 재생전력을 사용할 수 있나요?

글로벌 회원 가입과 별도로 국내 K-RE100에 참여할 수 있습니다. 이용하려는 수단별 자격과 신청 절차를 확인해야 합니다. [국내 제도 원문](https://www.knrec.or.kr/biz/introduce/new_policy/intro_kre100.do)

## 원자력도 RE100에 포함되나요?

RE100이 인정하는 재생에너지원 목록에는 원자력이 포함되지 않습니다. 무탄소 전원이나 저배출 전원 전체를 다루는 논의와 범위가 다릅니다. 또한 열을 생산하는 지열 설비를 설치했다는 사실만으로 재생‘전력’을 생산한 것은 아닙니다. [기술 기준 Section 3](https://www.theclimategroup.org/re100/technical-guidance)

## 녹색프리미엄은 의미가 없나요?

국내에서 안내하는 조달 수단 중 하나입니다. 제도상 인정 여부, 신규 설비 확대에 대한 기여, 배출량 산정상 효과, 비용은 다른 질문입니다. 목적과 근거를 나눠 평가하세요. [조달 방식](03-procurement.md)

## REC를 구매하면 전기요금이 없어지나요?

별도의 전기 구매는 계속됩니다. 인증서 비용만으로 공급전력 전체 비용을 비교하면 빠지는 항목이 생깁니다. [총비용 비교](03-procurement.md)

## 태양광 용량이 같으면 성과도 같나요?

일사량·음영·설치방향·손실·정지와 사용 시간대가 다르면 발전량과 자가소비량도 달라집니다. 실제 계량량과 실적 귀속을 확인해야 합니다.

## PPA가 항상 더 저렴한가요?

계약기간·부대비용·수요·요금 변화에 따라 달라집니다. 특정 사례의 계약 단가를 모든 사용자의 최종 부담으로 일반화할 수 없습니다. [비교 질문](03-procurement.md)

## 100%를 달성하면 제품도 탄소중립인가요?

전력 사용 실적만으로 공정·연료·원재료·운송 등 제품 전반의 배출이 사라지지는 않습니다. CBAM도 별도 기준으로 확인해야 합니다. [숫자와 주장](04-reading-claims.md)

## 2026년부터 매시간 재생전력을 맞춰야 하나요?

2026년 RE100 보고 지침에는 일률적인 24/7 의무가 없습니다. 고객사·개별 프로그램의 별도 요구는 따로 확인하세요. [동향 안내](02-trends.md)

## 최신 자료라는 표시를 어디까지 믿으면 되나요?

기존 동향 자료의 확인일은 2026-09-23이며 실무 해설은 2026-10-05 보강했습니다. 2026-10-08에는 K-GX 풀본·공식 발표·지분참여 FAQ를 추가하고, 국내 사용확인·2026 RE100 보고지침·Scope 2의 관련 부분을 재확인했습니다. 확인 범위는 [출처 목록](sources.md)에 개별 표시합니다. 원문의 갱신일과 적용 시점을 함께 보세요.

## ‘태양광 효율 15%’로 연간 발전량을 계산해도 되나요?

모듈 변환효율인지 설비이용률인지 먼저 확인해야 합니다. 용량 × 8,760시간 × 비율로 연간 발전량을 구할 때 사용하는 것은 설비이용률입니다. 두 비율은 서로 대체할 수 없습니다. [1·2·3MW 계산 예시](01-basics.md)

## 건물주와 입주자가 같은 태양광 실적을 각각 주장할 수 있나요?

동일한 전력량의 환경속성을 양쪽의 독립적인 재생전력 사용 실적에 중복 배분하지 않도록 해야 합니다. 소유권뿐 아니라 계량, 사용·판매량, 계약상 귀속과 증빙을 함께 확인하세요. [경계 검토표](05-checklist.md)

## 재생전력 100%이면 Scope 2 전체가 0인가요?

전력 외에 구매한 열·증기·냉방이 있는지, 어떤 산정 방식을 적용했는지부터 확인해야 합니다. 적격 재생전력 조달을 시장기반 계산에 반영하더라도 지역기반 결과가 자동으로 0이 되지는 않습니다. [가상 계산 예시](04-reading-claims.md)

## 녹색프리미엄과 PPA 중 어느 것을 먼저 검토해야 하나요?

목표 기한, 수요의 지속성, 요구되는 증빙과 비용 범위를 먼저 정하세요. 단기 부족량과 장기 기본 물량은 조건이 다릅니다. 녹색프리미엄의 추가요금과 PPA의 전력 포함 단가를 바로 비교하면 비용 범위를 혼동하게 됩니다. [같은 물량의 증분비용 비교](03-procurement.md)

## K-GX의 100GW는 대한민국이 RE100을 달성한다는 뜻인가요?

100GW는 2030년 국가 재생에너지 **설비용량 목표**입니다. 개별 조직의 전력사용을 100% 적격 재생전력으로 전환했다는 뜻이 아닙니다. 2035년 발전비중 30% 이상 목표와도 지표·연도가 다릅니다. [목표와 단위 비교](07-kgx.md#targets)

## 2027년 1월이면 REC가 모두 없어지나요?

전략의 본문은 2027년 1월 세부내용 마련, 일정표는 2027년 상반기 추진을 제시합니다. 기존 기업 계약·인증서·사용확인의 처리까지 확정한 문서는 아니므로, 세부 시행안과 경과조치를 확인해야 합니다. [REC 개편 해설](07-kgx.md#procurement)

## PPA 망사용료 지원 연장은 우리 기관에도 바로 적용되나요?

K-GX는 태양광 산업 인증제도 고도화 항목에서 지원 연장을 제시하지만, 해당 문서에는 대상·요율·기간이 없습니다. 실제 공고의 자격과 적용기간을 확인한 뒤 예산에 반영해야 합니다. [조달·지원 검토](03-procurement.md)

## 2030년에는 PPA를 100원/kWh에 살 수 있나요?

문서의 100원/kWh는 태양광 발전단가의 정책 목표입니다. 소비자의 PPA 전력가격·망 이용·정산·부족전력 등을 포함한 총비용을 보장하지 않습니다. [정책 목표와 견적의 차이](07-kgx.md#targets)

## 히트펌프를 도입하면 RE100 계획도 바꿔야 하나요?

연료·열을 전기로 대체하면 전력수요가 변하므로 목표 물량을 다시 계산해야 합니다. 효율개선으로 줄어드는 수요도 함께 반영합니다. 설치 자체가 재생전력 실적을 만드는 것은 아닙니다. [전기화 반영 계산](07-kgx.md#buildings)

## 짧은 용어집

| 용어 | 뜻 |
|---|---|
| K-GX | 한국형 녹색대전환. 에너지·산업·도시 등 전반의 전환을 다루는 국가 전략 |
| GW | 설비용량·출력 단위. 1GW = 1,000MW |
| ZEB / GR | 제로에너지건축물 / 그린리모델링. 구체적 기준과 적용대상은 해당 제도에서 확인 |
| PPA | 전력구매계약. 가격·기간·물량·정산 조건을 정하는 계약 |
| EAC | 전력의 에너지원 등 환경속성을 추적하는 인증서의 통칭 |
| REC | 재생에너지 공급인증서. 국내에서는 적용 제도와 가중치 등을 함께 확인 |
| 자가소비 | 자신이 생산한 전력을 자신이 소비하는 것 |
| Scope 1 | 조직이 직접 소유·통제하는 배출원에서 발생하는 직접배출 |
| Scope 2 | 구매한 전기·열·증기·냉방의 생산에 따른 간접배출 |
| Scope 3 | Scope 2 외에 가치사슬에서 발생하는 기타 간접배출 |
| 추가성 | 조달·투자가 기존 상황을 넘어 새 재생에너지 공급 등에 기여했는지 살피는 개념 |
| 24/7 매칭 | 소비와 적격 전력 생산을 시간대별로 대응시키는 접근 |
| 출력제어 | 전력망 운영 등 사유로 발전 출력을 제한하는 것 |
| LCOE | 설비 생애의 비용과 발전량을 기준으로 구한 단위 발전비용 |
| kWh / MWh | 전력량 단위. 1MWh = 1,000kWh |

더 자세한 정의와 적용 조건은 [출처 목록](sources.md)의 기술·회계 지침을 참고하세요.

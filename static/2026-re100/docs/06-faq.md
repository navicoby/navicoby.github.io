# 06. 자주 묻는 질문과 용어

[처음으로](../README.md) · [출처 목록](sources.md)  
자료 확인일: 2026-09-23

### RE100에 가입하면 이미 100%를 달성한 건가요?

가입, 목표 설정, 연간 실적 달성은 서로 다른 상태입니다. 발표의 목표연도와 실제 실적기간을 함께 보세요. [기본 개념](01-basics.md)

### 작은 기업이나 공공기관도 재생전력을 사용할 수 있나요?

글로벌 회원 가입과 별도로 국내 K-RE100에 참여할 수 있습니다. 이용하려는 수단별 자격과 신청 절차를 확인해야 합니다. [국내 제도 원문](https://www.knrec.or.kr/biz/introduce/new_policy/intro_kre100.do)

### 원자력도 RE100에 포함되나요?

RE100이 인정하는 재생에너지원 목록에는 원자력이 포함되지 않습니다. 무탄소 전원이나 저배출 전원 전체를 다루는 논의와 범위가 다릅니다. 또한 열을 생산하는 지열 설비를 설치했다는 사실만으로 재생‘전력’을 생산한 것은 아닙니다. [기술 기준 Section 3](https://www.theclimategroup.org/re100/technical-guidance)

### 녹색프리미엄은 의미가 없나요?

국내에서 안내하는 조달 수단 중 하나입니다. 제도상 인정 여부, 신규 설비 확대에 대한 기여, 배출량 산정상 효과, 비용은 다른 질문입니다. 목적과 근거를 나눠 평가하세요. [조달 방식](03-procurement.md)

### REC를 구매하면 전기요금이 없어지나요?

별도의 전기 구매는 계속됩니다. 인증서 비용만으로 공급전력 전체 비용을 비교하면 빠지는 항목이 생깁니다. [총비용 비교](03-procurement.md)

### 태양광 용량이 같으면 성과도 같나요?

일사량·음영·설치방향·손실·정지와 사용 시간대가 다르면 발전량과 자가소비량도 달라집니다. 실제 계량량과 실적 귀속을 확인해야 합니다.

### PPA가 항상 더 저렴한가요?

계약기간·부대비용·수요·요금 변화에 따라 달라집니다. 특정 사례의 계약 단가를 모든 사용자의 최종 부담으로 일반화할 수 없습니다. [비교 질문](03-procurement.md)

### 100%를 달성하면 제품도 탄소중립인가요?

전력 사용 실적만으로 공정·연료·원재료·운송 등 제품 전반의 배출이 사라지지는 않습니다. CBAM도 별도 기준으로 확인해야 합니다. [숫자와 주장](04-reading-claims.md)

### 2026년부터 매시간 재생전력을 맞춰야 하나요?

2026년 RE100 보고 지침에는 일률적인 24/7 의무가 없습니다. 고객사·개별 프로그램의 별도 요구는 따로 확인하세요. [동향 안내](02-trends.md)

### 최신 자료라는 표시를 어디까지 믿으면 되나요?

이 프로젝트의 확인일은 2026-09-23입니다. 그날까지 확인한 공식 자료를 설명하며, 실시간 가격이나 모든 제도의 최종 유효성을 보증하지 않습니다. 원문 갱신일과 적용 시점을 함께 확인해 주세요.

## 짧은 용어집

| 용어 | 뜻 |
|---|---|
| PPA | 전력구매계약. 가격·기간·물량·정산 조건을 정하는 계약 |
| EAC | 전력의 에너지원 등 환경속성을 추적하는 인증서의 통칭 |
| REC | 재생에너지 공급인증서. 국내에서는 적용 제도와 가중치 등을 함께 확인 |
| 자가소비 | 자신이 생산한 전력을 자신이 소비하는 것 |
| Scope 1 | 조직이 직접 소유·통제하는 배출원에서 발생하는 직접배출 |
| Scope 2 | 구매한 전기·열·증기·냉방의 생산에 따른 간접배출 |
| Scope 3 | Scope 2 외에 가치사슬에서 발생하는 기타 간접배출 |
| 추가성 | 조달·투자가 기존 상황을 넘어 새 재생에너지 공급 등에 기여했는지 살피는 개념 |
| 24/7 매칭 | 소비와 적격 전력 생산을 시간대별로 대응시키는 접근 |
| 출력제어 | 전력망 운영 등 사유로 발전 출력을 제한하는 것 |
| LCOE | 설비 생애의 비용과 발전량을 기준으로 구한 단위 발전비용 |
| kWh / MWh | 전력량 단위. 1MWh = 1,000kWh |

더 자세한 정의와 적용 조건은 [출처 목록](sources.md)의 기술·회계 지침을 참고하세요.

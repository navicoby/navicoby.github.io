# 커피 브루잉 · 씨앗에서 잔까지

김수영의 세 커피 원고를 통합 편집한 한국어 웹 안내서입니다.

- 공개 주소: https://navicoby.github.io/coffee-brewing/
- 원저자: 김수영 · 더윌로우즈
- 웹판: 1.0, 2026-09-23
- 구성: 12개 본문 장, 용어 사전, 자료 소개, 배합 계산·타이머, 브라우저 내 추출 기록

## 운영

외부 라이브러리, 분석 스크립트, 로그인, API 키 없이 동작하는 정적 HTML/CSS/JavaScript입니다. 기존 Hugo 저장소의 `static/coffee-brewing/` 폴더에 두면 같은 경로로 배포됩니다. 빌드 도구 없이 이 폴더를 HTTP 서버로 열어 미리 볼 수도 있습니다.

읽기는 JavaScript 없이 가능합니다. 검색·계산·타이머·기록에는 JavaScript가 필요합니다. 기록은 사용자가 저장 버튼을 누를 때 이 브라우저의 localStorage에 저장하며 서버로 보내지 않습니다. CSV와 JSON 내보내기를 지원합니다. 호스팅 제공자의 일반 접속 로그는 사이트 코드와 별개입니다.

## 편집과 자료

`downloads/coffee-brewing-guide.md`가 통합 편집 원고입니다. 장별 HTML과 `read.html`은 이 웹판의 읽기 화면입니다. 원문 PDF는 이 폴더에 포함하지 않습니다. 원고의 조건과 사실을 교정·보완한 내역 및 공식 참고 자료는 `chapters/about.html`에 정리했습니다.

원저작물의 권리는 저자에게 있습니다. 별도의 재배포 허락을 뜻하는 오픈소스 라이선스는 부여하지 않았습니다.

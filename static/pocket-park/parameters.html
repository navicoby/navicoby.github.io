AX RESEARCH / RESOURCE PARAMETERS / PILOT 01

몇 명, 몇 대를 함께 투입할 것인가

굴삭기·작업반·직종별 인원을 매개변수로 관리하고, 같은 자원 조건에서 다음 작업을 선택하는 정책을 학습했다.

P0에서는 공기 단축이 관찰되었다. 평균 차이는 +2.73일이다. P7에서는 공기 단축이 관찰되었다. 평균 차이는 +1.26일이다. 합성 부지의 첫 예비실험으로, 현장 검증이나 전역 최적 해를 뜻하지 않는다. 인력·장비 증원에 따른 효과와 학습에 따른 효과를 구분한다.

이 예비실험은 R1의 균등4구역 기준이다. 식재·시설 기준의 R2 공구 조정안은 별도 검토이며, 새 경계로 재학습한 결과가 아니다.

01 / PARAMETERS

기본값과 검토 범위

대지 2,000㎡, 설계·물량과 근무달력(주 5일, 하루 8시간)은 고정한다. 굴삭기 2대는 검토 상한이며, 실제 진입 폭·작업반경·대기 공간의 적합성은 아직 확인하지 않았다.

평떼 1개 조는 조경공 1명 + 보통인부 4명이며 기준 시공량은 150㎡/8시간이다. 2개 조는 10명, 3개 조는 15명이다. 현재는 서로 다른 구역에 조를 배정한다. 한 구역 작업을 2배·3배로 가속하는 가정은 적용하지 않았다. 300×300mm 평떼 규격은 유지한다.

작업반 수는 동시 착수의 상한이고, 직종별 인원은 여러 공종이 함께 쓰는 자원이다. 예를 들어 관목 1개 반(조경공 3명·보통인부 1명)과 평떼 1개 조를 동시에 운영하려면 조경공 4명·보통인부 5명이 필요하다. 작업반만 늘려도 이 인원 조건이 충족되지 않으면 대기한다. 토공반은 아직 직종별 인원을 확정하지 않은 묶음 자원이므로 전체 현장 인원에 합산하지 않는다.

02 / FEASIBILITY

증원보다 먼저 지켜야 할 조건

  1. 전체 표토 정리·부지정지는 A~D 작업구역을 동시에 점유한다.
  2. 우수관·집수정 설치와 관저고 검토는 전 계통을 하나의 작업으로 관리한다. 작업반이 늘어도 개별 구간으로 자동 분할하지 않는다.
  3. 관목 식재와 블록포장은 서로 다른 구역이고 선행 작업·인원·동선 조건이 충족될 때 병행할 수 있다.
  4. 반입구는 1개 슬롯, 같은 구역에는 동시에 1개 작업만 허용한다. 완료된 포장의 장비 통행 제한을 적용한다.
  5. 62개 작업의 공개 원본은 경계석 4개 구역 작업을 유지한다. 경계석 일괄 시공을 반영한 별도 59개 작업 검토안과 이번 결과를 혼합하지 않았다. 논문 본 실험 전에 공정 기준을 통일해야 한다.

이 규칙은 사건 시뮬레이션의 제약이다. 실제 장비 충돌·안전거리·자재 적치·관저고 수치 검측을 수행했다는 의미는 아니다.

04 / REINFORCEMENT LEARNING

자원이 같을 때, 다음 작업 선택을 학습

선행 작업·근무시간·자원·작업구역 조건을 통과한 작업만 후보로 제공하는 선형 REINFORCE 정책을 학습했다. 작업시간·후속 작업 길이·가용 자원 등의 17개 특징을 이용하며, 미래 강우나 실제 생산성 난수는 정책에 제공하지 않는다. 진행 중인 작업은 우선 재개하고, 자원이 남으면 가능한 작업을 추가 배정한다.

학습은 초기화 시드 3개 × 192회, 검증자료는 8개 시나리오로 구성했다. 각 시드에서 8·16·24회차 묶음의 정책을 검증하고 선정했다. 이후 학습·검증에 쓰지 않은 24개 시나리오에서 세 가지 기존 규칙, 무작위 선택, RL 정책 3개를 P0·P7의 같은 자원 조건으로 비교했다.

# 챕터 원본 템플릿

`books/python-geospatial/pages/chapters/<slug>.md`에 저장한다. 아래 frontmatter와 절을 채우고 `books/python-geospatial/pages.json`의 순서에 등록한다. `draft` 글을 완성 링크로 공개하지 않는다.

```yaml
---
title: "장 번호 · 분석 질문이 드러나는 제목"
description: "자료·분석·결과를 한 문장으로 설명"
eyebrow: "PART 02 / VECTOR"
order: 10
---
```

본문 예시:

```markdown
목표: 무엇을 계산하고 어떤 판단에 쓸 수 있는가.
선수: Python 배열 / 03장 CRS. 시간: 예상 실습 시간.
데이터: 가상/실측, 면적, 단위, 출처. 환경: 검증 버전 페이지 링크.

## 개념
표현·연산을 하나의 공간 질문으로 설명한다.

## 왜 필요한가
조경·도시 의사결정 한 가지와 결과의 한계를 제시한다.

## 핵심 API
API | 입력 | 출력 | 주의사항 표. 자세한 API 나열은 공식 문서로 연결한다.

## 최소 실행 예제
설치/실행 방법, 완전한 import, 입력 생성·출력 확인. 실행 원본과 본문을 맞춘다.

## 조경·도시 실무 예제
한국 공공데이터와 OSM/위성영상으로 교체하는 절차, 필드 매핑과 품질 점검.

## 시각화
실제 결과 그림, 범례·단위·대체 텍스트. 인터랙티브 지도에 정적 대안.

## 흔한 오류
증상 → 원인 → 수정 → 결과 점검.

## 연습문제
재현 1개, 조건 변경 1개, 비판적 해석 1개. 접을 수 있는 답/검산 힌트.

## 다음 단계
다음 분석으로 연결되는 데이터나 질문. 미집필 장은 로드맵으로 연결한다.

## 출처
공식 문서·원 논문·데이터 상세 페이지 직접 링크, 확인일·자료 기준일 구분.
```

일관성을 위한 공통 UI는 빌더가 생성한다. 본문에 h1·전체 HTML shell·임의 CDN 스크립트를 중복 삽입하지 않는다.
